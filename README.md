# Ruta Bíblica — La Gran Historia

Ruta interactiva de estudio bíblico con 20 etapas, progreso local, mini quizzes y lectura integrada de la Reina-Valera 1909.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

## Publicación

Cada push a `main` ejecuta automáticamente el workflow de GitHub Pages.

La aplicación incluye la Reina-Valera 1909 en el directorio `client/public/data/rvr1909/`. La RVR 1960 se ofrece como enlace externo para respetar sus condiciones de uso.
